# Loon X 信息流过滤：暂停运行

## 当前状态（2026-11-17）

用户安装实验版后反馈：X 官方 App 出现“帖子暂时无法载入”，信息流广告仍然可见。此前仅使用构造响应测试，没有验证 App 实际接口、数据结构和 HTTPS 解密兼容性。

当前发布的插件是**无活动脚本、无 MitM 域名的暂停版本**，不是修复成功的去广告版本。旧版本已安装在手机上时不会因仓库更新自动立即失效，**请先在 Loon 中停用该插件**。更新原订阅地址可获取暂停版本：

```text
https://raw.githubusercontent.com/TomisatoNao/qx-pt-rules/main/plugins/Loon/X-AdFilter.plugin
```

插件原型脚本和模拟测试仍留在仓库供排查，不能将测试通过视为 App 兼容性验证。

## 已知与未知

- 截图能确认广告残留，以及首页显示加载错误。
- 截图不能区分 HTTPS 解密失败、响应修改不兼容、接口未匹配、脚本未执行、缓存或其他网络故障。
- 广告卡片里的“来自某网站的广告”是广告展示信息，不能据此判断拦截该网站就能删除信息流卡片。
- 不应封禁 abs.twitter.com、abs.twimg.com 或全部 Twitter/X API 来尝试掩盖问题。

## 下一步需要的证据

优先使用已经出现故障时的 Loon 日志，不要求反复开启故障插件：

1. api.twitter.com、api.x.com 等相关请求的 TLS / 连接错误。
2. X-AdFilter 脚本日志是否执行、有无报错、removed 计数。
3. 如果确实成功解密并运行，才根据实际接口和脱敏响应结构继续适配。

没有脚本日志不能直接证明是证书固定。请勿公开 Cookie、Authorization、令牌、证书私钥或完整个人时间线。

若停用后仍异常，先关闭并重新打开 X；其他插件如也解密这些域名，需要另行检查。本次仓库变更未修改任何 PT 规则或代理节点。
